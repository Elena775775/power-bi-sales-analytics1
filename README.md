# Power BI Sales Analytics Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard designed to analyze sales performance, finance, logistics, and employee order activity. It transforms order data into business insights through key performance indicators (KPIs), tables, and report pages.

## 🎯 Project Objectives

- Monitor overall sales performance.
- Analyze shipping and order fulfillment.
- Track discounts and on-time order performance.
- Explore employee order history and activity.
- Present business metrics in a clear, interactive format.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** — dashboard development and data visualization
- **Data modeling** — organizing data for reporting
- **DAX** — measures and KPI calculations, where applicable
- **Data visualization** — KPI cards, tables, and report pages

## 📈 Dashboard Pages

The report includes the following pages:

### 1. Finance
A view focused on financial performance and relevant business metrics.

### 2. Logistics
A view focused on shipments and order fulfillment performance.

### 3. Employee Analysis
An overview of employee-related order activity and performance.

### 4. Employee Orders
An order-history table with metrics including:

- **Total Sales:** 232.89K
- **Shipments Count:** 151
- **Total Discount:** 6.91%
- **On-time Order Rate:** 94%

The displayed values reflect the report view shown in the project screenshot and may change with filters or updated data.

## 💡 Key Insights

The displayed Employee Orders page highlights sales volume, shipment count, discount levels, and order timing. These KPIs provide a starting point for exploring operational performance and order fulfillment.

Further analysis can investigate differences across employees, identify delivery patterns, and examine relationships between discounts and sales.
